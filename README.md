# EnglishUp 🚀

Your personal English coach in a **single HTML file** (`index.html`). No server, no install.

**Live app:** https://manmohankaushik534-collab.github.io/englishup/

- Progress is saved in your browser (localStorage). Use **Settings → Download backup** now and then.
- AI feedback uses your own Claude API key, entered in **Settings** inside the app. The key stays only in your browser. It is never saved in the code or on GitHub.

## Turn on GitHub Pages (one time)
Repo → **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, folder `/ (root)` → Save.
After 1–2 minutes the live link above starts working.

## Run on your computer
Double-click `index.html`.

## Get a Claude API key
https://console.anthropic.com/settings/keys → Create Key → copy it → paste it in EnglishUp **Settings** → Save.
